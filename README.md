# Ireen's To-Do List - Week 5

Week 5: DOM Manipulation - Interactive To-Do List App by Ireen Kathure

## Live Demo
https://ireenkathure.github.io/iyf-s12-week-05-ireenkathure/

## Features
- Add new tasks
- Mark tasks as completed with checkbox
- Delete tasks
- Filter: All / Active / Completed
- Clear Completed button
- Items left counter
- Saves tasks in LocalStorage - they stay even after refresh

## Files
- `index.html` - HTML structure
- `styles.css` - Styling
- `app.js` - JavaScript logic, DOM manipulation, localStorage

## How to run
Open `index.html` in browser, or visit the Live Demo link above.
